## 무엇을 도와주나요?

- 사이트의 글자·색·여백·버튼을 정하는 화면 설계
- 읽는 순서와 시각적 구분을 다듬는 디자인 개선
- 모바일 화면·접근성·사용성 등 완성 후 점검

AI 모델 자체를 바꾸거나 결과의 완성도를 보장하는 프로그램은 아닙니다. 이미 정한 브랜드색과 서체를 우선하며, 결과 화면과 버튼은 직접 확인해야 합니다.

설치나 파일 접근 확인이 나오면 요청 내용을 읽고 진행해 주세요.

### 설치 확인

```text
쌩초보 1주차 스킬팩과 포함된 자료가 설치됐는지 확인해 줘. 화면 설계, 글자·버튼 다듬기, 접근성 점검 자료를 각각 실제로 열고, 빠진 파일이 있으면 알려 줘.
```

### 사이트에 적용

```text
쌩초보 1주차 스킬팩을 적용해서 내 사이트의 글자·색·버튼·모바일 화면을 점검해 줘. 내가 정한 브랜드색과 서체는 유지해 줘.
```

어사이드에 설치하는 안내입니다. 다른 AI 앱에 자동으로 설치되지는 않습니다.

## 사용 환경과 확인 범위

- Mac에서 ZIP 재추출, 내부 자료 연결, 예시 검색과 표 직접 읽기를 확인했습니다.

- 검색 스크립트는 Python 3 표준 라이브러리를 사용합니다. Python을 실행할 수 없으면 포함된 문서와 자료를 직접 읽도록 구성했습니다. 두 방식은 같은 검증 결과로 취급하지 않습니다.
- 새 계정에서 채팅 첨부부터 설치 완료까지의 전체 과정과 Windows 실행은 미확인입니다.
- 별도 프로그램 설치·결제·외부 서비스 연결을 자동으로 진행하지 않습니다. 사용 중인 AI 서비스의 이용 조건과 사용량은 별도입니다.
